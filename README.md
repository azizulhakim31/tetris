# Tetris

A browser-based Tetris game built with HTML, CSS, and vanilla JavaScript.

## Live Demo

[Play Tetris](https://your-username.github.io/tetris/)

## Features

- Classic falling-block gameplay
- Score, level, and line tracking
- Next-piece preview
- Pause and restart controls
- Keyboard controls

## Getting Started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Start playing.

For the best local development experience, serve the project with any static web server.

## Controls

| Action | Control |
| --- | --- |
| Move left/right | Left and Right Arrow keys |
| Rotate | Up Arrow key |
| Soft drop | Down Arrow key |
| Hard drop | Spacebar |
| Pause | `P` |

You can also use the on-screen **Pause** and **Restart** buttons.

## Project Structure

- `index.html` - Game markup
- `style.css` - Game layout and styling
- `script.js` - Game logic and controls
- `LICENSE` - MIT license
